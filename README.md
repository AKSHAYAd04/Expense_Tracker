# Expense Tracker Application
## Project Description
A lightweight console application developed to manage daily expenses, log expenditures, and monitor budget limits effectively. 

 Technologies Used:
   Python, 
   Git & GitHub for Version Control

 Features:
       Add Expense: Allows logging amounts along with categories,
       View Records: Displays a history of tracked expenses along with a calculated total budget sum,
       Clear Logs: Resets the list to start fresh.
